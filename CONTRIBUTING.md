# Contributing

Thank you for your interest. This repository is documentation-first, and the implementation it documents is not yet distributed here, so the most useful contributions today are to the documentation itself.

## What we welcome

- Corrections to anything that is inaccurate, unclear or out of date relative to the release the page names.
- Questions filed as issues: if a page left you unable to do something, that is a documentation defect.
- Reports of claims that are not evidenced. Every factual statement about the system should be traceable to the accepted release or its acceptance run; if you find one that is not, please say so.

## What we will not merge

- Changes that present the repository as an installable or turnkey product.
- Marketing claims, ROI figures, testimonials or customer results. None exist yet, and we would rather publish evidence than numbers.
- Edits to `LICENSE`. The Apache License 2.0 text is reproduced unmodified from the Apache Software Foundation.

## How

Open an issue or a pull request against `main`. Keep pull requests small and say which page and which release they concern. By contributing you agree that your contribution is licensed under the Apache License 2.0, as stated in the License's section 5.

## Source contributions

When a source release is published it will have its own contribution guide covering tests, independent review and the reviewed-installer process the project uses. Until then, please do not submit source.
