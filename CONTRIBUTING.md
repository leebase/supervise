# Contributing

Thank you for your interest. This repository holds the public source build of /supervise (v0.x) and the documentation
of the private production deployment it derives from.

## What we welcome

- Issues: defects, unclear documentation, and claims that are not evidenced by the code or a recorded run.
- Pull requests for documentation and for backend drivers (new harnesses behind the backend interface in
  `supervise/backend.py`). Keep them small, include tests, and say what you ran.

## What we will not merge

- Changes to `LICENSE` (the Apache License 2.0 text is reproduced unmodified).
- Marketing claims, ROI figures, testimonials or customer results.
- Changes that weaken a documented security property without a reviewed reason.

## Licensing and sign-off

Contributions are licensed under the Apache License 2.0 (section 5, inbound = outbound). Sign off every commit with the
Developer Certificate of Origin (`git commit -s`). There is no CLA. The maintainer is the sole merger.

## Security issues

Report vulnerabilities privately through GitHub's private vulnerability reporting for this repository, not in public
issues.
